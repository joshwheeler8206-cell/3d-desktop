Marine Corps - 3D Wallpaper for Lively  (Windows 11)
=================================================

WHAT THIS IS
    The same 3D desktop scene, repainted in Marine Corps scarlet and gold with
    a globe-and-anchor emblem, SEMPER FIDELIS and a live clock - as your ACTUAL
    desktop background, sitting BEHIND your icons.  No window, no taskbar item,
    nothing to click.  Four looks: Scarlet & Gold, Night Patrol, Sunset Watch
    and Gold Standard.

THE EASY WAY (recommended)
    1. Install Lively Wallpaper (free) from the Microsoft Store.
    2. In Lively: Library -> Add -> select THIS WHOLE FOLDER.
    3. Right-click the wallpaper -> Change -> Scene / Speed / options.

YOU DO NOT NEED ADMIN RIGHTS.  Lively is a normal per-user app.

IF EDGE SHOWS A BLANK PAGE WHEN YOU OPEN THE HTML DIRECTLY
    Edge blocks local files from rendering media.  Fix once:
      edge://settings/content -> Files -> Allow
    (Lively itself is unaffected - it renders in its own WebView2 host.)

SPEED ON AN OLD PC
    In Lively's per-wallpaper options turn on "Lite mode (weak laptops)".

CHANGING SETTINGS
    Lively saves your choices per display.  "Restore Default" resets them.
    To use the scene on another PC: right-click in Lively -> Export .zip.

THIS FOLDER CONTAINS
    usmc-wallpaper.html    the wallpaper itself (offline, no internet)
    LivelyProperties.json  the scene / speed / parallax / lite options
    README-LIVELY.txt      this file
