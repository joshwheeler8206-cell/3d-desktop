3D DESKTOP THEMES  -  U.S. AutoForce  &  United States Marine Corps
==================================================================

Two animated desktop themes in one attachment.  Pick the one you like, or try
both.  Everything works offline, needs no install, and costs nothing.

WHAT YOU GET
    AutoForce 3D Desktop ....... company logo, the line
                                  "Safety is Not a Priority - It's a
                                  Prerequisite", and a live clock.
    USMC 3D Desktop ............ Marine Corps globe-and-anchor emblem,
                                  "Semper Fidelis", and a live clock.

    Each has four looks.  Click the SCENE button (or press 1-4) to switch:
        AutoForce:  Night Highway (default), Crimson Dawn, Indigo Deck, Stealth
        USMC:       Scarlet & Gold (default), Night Patrol, Sunset Watch,
                    Gold Standard


THE EASY WAY  -  about 30 seconds, no install
--------------------------------------------
1. Save the attachment to your Desktop (if you have not already).
2. RIGHT-CLICK the .zip file > Extract All > Extract.
3. Open the folder that appears.
4. Double-click  START-HERE.html  and pick a theme.

    That is it.  Each theme opens in a borderless full-screen window.
    To close it, press  ESC.

    If you would rather skip the chooser, just double-click
    autoforce-3d-desktop.html  or  usmc-3d-desktop.html  directly.

    You can move the two .html files anywhere you like - they are
    self-contained and work with no internet connection.


MAKING IT A REAL DESKTOP BACKGROUND (optional, better)
------------------------------------------------------
The theme above is a window, so it covers your icons while it is open.

For the same theme as your ACTUAL desktop background - behind your real
icons, with the clock ticking - use the free "Lively Wallpaper" app:

    1. Microsoft Store > search "Lively Wallpaper" > Install (free, ~1 min).
    2. Lively > Library > Add > select the USMC-3D-Lively folder
       (or AutoForce-3D-Lively for the company one).
    3. That is it.  Right-click the wallpaper to change Scene and Speed.

    Lively installs per-user, so no administrator password is needed.


WANT DESKTOP ICONS?
-------------------
Press F while the theme is open for true full screen; press P for a plain
scene with no logo or clock.  For icons plus the animated background, use the
Lively option above.


CONTROLS
--------
    move mouse ....... show the buttons
    1 2 3 4 .......... change scene
    SPACE ............ pause / resume the animation
    up / down ........ animation speed
    F ................ full screen
    H ................. hide / show the logo and clock (Desktop theme only)
    P ................. plain scene, no logo or clock (Desktop theme only)
    ESC ............... close


INSTALLING DESKTOP SHORTCUTS (optional)
--------------------------------------
install.bat / install.ps1 create Desktop + Start Menu shortcuts.  You do not
need them - the .html files work on their own.

Some company email systems remove .bat and .ps1 files from messages.  If the
files are missing from the folder you extracted, just ignore them and use the
double-click method above; nothing is lost.

Right-click install.bat > Run as administrator is NOT required.


IF SOMETHING GOES WRONG
-----------------------
Blank / white screen when you open the .html directly
    Microsoft Edge blocks local files from drawing.  Fix it once:
        1. Open Edge.  In the address bar type:  edge://settings/content
        2. Find "Files" and set it to Allow.
        3. Close Edge and open the theme again.
    (The Lively option is not affected by this.)

Nothing happens / a security warning appears
    Right-click the .html > Properties > tick "Unblock" > OK, then open it.

The animation is choppy
    Move the mouse to bring up the buttons, then click LITE.  That drops the
    stars, speed lines and scanlines.  On a laptop, that is the difference
    between smooth and not.

The theme opened small instead of full screen
    Press F.

Both themes have been tested in Microsoft Edge and Google Chrome on Windows.


REMOVING IT
-----------
Delete the extracted folder.  If you used the installer, run uninstall.bat
(or delete the folder it printed, usually
  C:\Users\YourName\AppData\Local\3D-Desktop
).
