Using the desktop theme

  • Click Open the theme and it runs in a normal browser tab. Press F for full screen.
  • To keep it, download the ZIP above, right-click > Extract All, then double-click START-HERE.html. After that it opens in a borderless full-screen window — press ESC to close.
  • For a desktop shortcut, run install.bat in the extracted folder. It is optional and needs no admin rights. Some work email systems strip .bat and .ps1 files — if they are missing, ignore them and use the double-click method; nothing is lost.
  • Want it as your actual desktop background, behind your icons? The ZIP includes a Lively folder for that — install the free “Lively Wallpaper” app from the Microsoft Store, then in Lively choose Library > Add and pick the AutoForce-3D-Lively folder from the extracted ZIP.

Printing the huddle

  • In the generator, pick the week (or leave it on the current one) and the language, then click Print / Save as PDF.
  • Choose Save as PDF instead of a printer to send it out or post it.
  • Both languages together is a two-page PDF — one page per language.
  • The animated background is off by default so nothing interferes with printing. There is a 3D Deck button if you want the animated look for presenting.
If the animation is choppy — move the mouse to bring up the buttons and click LITE. That drops the stars, speed lines and scanlines, which is usually the difference between smooth and not on an older laptop. Press P for the plain scene.
